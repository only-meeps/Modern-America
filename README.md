# Modern America
A BepInEx mod to add some small features to the Landfall Archives game Medieval America.

## Progress
Currently this mod is in the beta phase. Some maps have been added (due to bug fixes) and more are on the way (from bringing back old maps).


## Plans
I'm currently planning to add more maps first, then maybe more guns, and probably some more music as well. The game seems to have some team deathmatch code that I could test out, but that seems somewhat far off. Also an ingame map editor is on my todo list, but that might be a year out
