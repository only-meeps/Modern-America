# Modern America
A BepInEx mod to add some small features to the Landfall Archives game Medieval America.

## Progress
Currently this mod is in the beta phase. Some maps have been added (due to bug fixes) and more are on the way (from bringing back old maps).


## Plans
I'm currently planning to add more maps first, then maybe more guns, and probably some more music as well. The game seems to have some team deathmatch code that I could test out, but that seems somewhat far off. Also an ingame map editor is on my todo list, but that might be a year out

## Installation
1. Download BepInEx version BepInEx_win_x64_5.4.23.5.zip (others might work, not sure) from this repo: https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
2. Find Landfall Archives in your steam library
3. Click the settings icon and hover over manage, then click "browse local files"
4. Open the "Archive" folder
5. Find Medieval America
6. Extract BepInEx to this folder
7. Run the game (either from the steam launcher or the .exe file) to install BepInEx
8. Close the game
9. Download the latest release of Modern America
10. Extract it to the Medieval America/BepInEx/plugins folder
11. Run the game!
