# Modern America
A BepInEx mod to add some small features to the Landfall Archives game Medieval America.

## Progress
Currently this mod is in the alpha phase, just testing out how the game works and adding some debugging.


## Plans
I'm currently planning to add more maps first, then maybe more guns, and probably some more music as well. The game seems to have some team deathmatch code that I could test out, but that seems somewhat far off.
